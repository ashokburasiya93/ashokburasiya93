## Featured project
### [CloudBill Detective](https://github.com/ashokburasiya93/cloudbill-detective)
Cost tools tell you the cloud bill went up. CloudBill Detective tells you which change caused it, who owns it, and the fix to approve.
- Joins AWS billing line items with the change log (deploys, Terraform, CloudTrail) to find the cause of every sustained cost change, with evidence and ruled-out red herrings
- Splits usage from price, routes each case to an owner, drafts a fix for human approval; read-only by design
- Every number in AI-written text is fact-checked; 12 launch evals run as a build gate
- Full AI PM package: user research, AI opportunity map, PRD with North Star metric, cost model, deck
